# Multi-Agent project for CSIT5520, HKUST

A Multi-Agent Collaboration using Large Language
Models (LLMs) to solve multi-step software engineering tasks designed for the CSIT5520 NLP project at HKUST.

## 1. Setup Environment

It is recommended to use a virtual environment to manage dependencies.

```bash
# 1. Create a virtual environment
python3 -m venv venv

# 2. Activate the environment
# For macOS/Linux:
source venv/bin/activate
# For Windows:
venv\Scripts\activate

# 3. Install required dependencies
pip install -r requirements.txt
```

## 2. Setup Api

Create a .env file in the project root directory with your Azure OpenAI credentials. Ensure the endpoint and deployment name match your allocated resources.

```bash
AZURE_OPENAI_API_KEY=YOUR_API_KEY
AZURE_OPENAI_ENDPOINT="https://hkust.azure-api.net/"
AZURE_OPENAI_API_VERSION="2025-02-01-preview"
AZURE_OPENAI_CHAT_DEPLOYMENT="gpt-5-mini"
```

## 3. Execution Instructions
Ensure your virtual environment is activated and the .env file is properly configured before running the scripts. Run all commands from the root directory of the project.

### 3.1 Run the Zero-shot Baseline
To generate the initial baseline results without the execution feedback loop:

```bash
python3 src/main_zeroshot.py
```

### 3.2 Run the Full Multi-Agent Pipeline
To run the full AgentCoder execution loop. The orchestrator isolates generation, testing, and execution, utilizing a local Python sandbox for deterministic feedback.

```bash
python3 src/main.py
```
(Note: You can configure the maximum number of refinements—e.g., 1, 2, or 3—within the main script to replicate the ablation study).

### 3.3 Evaluate Results
To evaluate the generated Python completions against the official HumanEval hidden test cases:

```bash
python3 src/eval/eval.py
```
The evaluation metrics will be exported as JSON reports in the results/ directory.

## 5. Evaluation & Key Findings
This project implements an ablation study to find the optimal trade-off between generation accuracy and computational cost across 164 Python algorithmic tasks:

- The Baseline: The base gpt-5-mini model achieves a strong zero-shot performance of 96.34% True Pass@1.

- The "Sweet Spot" (Max 2 Refines): The full multi-agent loop pushes the ceiling to 97.56% True Pass@1, requiring an average of only 1.18 attempts per task.

- The Over-refinement Phenomenon: Pushing the limit to Max 3 Refines causes accuracy to drop (95.73%) as the Programmer Agent begins to overfit to overly strict or hallucinated edge cases generated by the Test Designer.
