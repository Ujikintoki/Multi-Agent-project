# Multi-Agent Project for CSIT5520, HKUST

A multi-agent collaboration system using Large Language Models (LLMs) for automated code generation, test generation, and execution feedback, designed for the CSIT5520 NLP course project at HKUST.

Our project is inspired by the idea of separating the coding workflow into multiple specialized agents:
- **Programmer Agent**: generates code for HumanEval tasks
- **Test Designer Agent**: generates independent test cases for HumanEval tasks
- **Test Executor Agent**: executes generated code against generated tests and returns feedback

The current implementation focuses on the **HumanEval** benchmark.
